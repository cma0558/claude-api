# Claude API 100 美元充值：官方 Console 充值步骤、额度过期规则，以及国内卡付不进去时的替代路径

很多人搜"Claude API 100 美元充值"，其实是卡在同一个位置：安安静静想给账户加 100 刀，结果发现付款页怎么也过不去。而在充值之前，还有个更常见的问题——这 100 美元到底该充给谁。

先把这件事说清楚，后面的选择会轻松很多。

## 你打算充的这 100 美元，可能进三个完全不同的账户

这三个体系彼此不通，余额也不共享：

- **Anthropic Console 的预付额度（credits）**：给 API、Workbench（playground）和 Claude Code 用。官方帮助中心写得很明确，额度覆盖 API 访问、playground 使用和 Claude Code。
- **claude.ai 上的 Pro / Max 订阅**：这是网页版和客户端的会员，按月订阅，和 API 额度不是一笔钱。
- **第三方平台自己的余额**：中转站、聚合平台、代付平台里的钱存在平台账户上，不在 Anthropic 名下。

这一点经常被搞混。买了 Max 不会顺手给你 API 额度，充了 API 额度也不会解锁网页版会员。如果你打算在自己的代码里调 Claude，要充的是第一类，也就是 Console 里的 credits。

## 官方充 $100 的完整流程

在 Console 里充值本身不难，麻烦的都在付款环节。

1. 用拥有 Admin 或 Billing 角色的账号登录 Console。
2. 进 **Settings → Billing**。
3. 点 **Buy credits**，弹窗里的金额选项通常是 **$5 / $20 / $100**，也可以自填其它金额。
4. 展开账单地址（Billing address）并填写。地址必须和发卡行记录一致，差一个拼写都可能被拒。
5. 填卡信息。地址填完，卡号栏才展开。
6. 确认摘要，注意这里会单独列出税额，最后按下购买按钮。

有开发者记录的实测过程是：选 $20 额度，账单地址填日本，摘要里显示税额 $2.00，合计 $22.00。也就是说，你买的额度面值和实际扣款不是一回事，税费取决于账单地址所在的国家或地区。买 $100 的话，实际扣款大概率是 100 美元出头。

几个容易踩的点：

> 官方只收国际信用卡，不支持支付宝、微信，也不接 PayPal、Venmo 这类第三方钱包。额度自购买之日起一年过期，且不能延期，所有额度购买概不支持退款。失败的请求不计费，但如果客户端在一条本会成功的请求中途断连或超时，这笔请求照常计费。

充值成功后余额立即到账，同页可以看到可用余额和使用量，历史账单里也会多一条记录。想省事的话，把 Auto-reload 打开并设一个阈值（比如余额低于 $50 时自动补 $100），比每次都手动点一遍省心。生产环境因为余额见底而中断，是完全可以避免的低级事故。

## 充之前一定要看的天花板：层级和月支出上限

Anthropic 的账户有使用层级（usage tier）机制，层级决定了每分钟请求数、每分钟 token 数和每个月的支出上限。

这里有个坑值得单独说：**层级不是充得多就能买上去的。** 官方帮助中心的口径是层级自动分配，没有哪笔充值能直接提升层级。但网上流传着各种"累计充值 $5 就进 Tier 1、累计 $40 就升 Tier 2"的整理表格，不同来源给出的门槛数字彼此并不一致，也和官方口径对不上。与其照着第三方表格规划充值金额，不如充值前直接看 Console 里的 Limits 页面，那里显示的是你账户当前的实际情况。

另外两件事比层级更现实：

- 月度支出上限按自然月计算，触顶后 API 会停到下个月 1 日 UTC，即使余额还有钱也调不动。
- 你可以在 **Settings → Billing** 的 Spend limits 里自己设一个更低的上限。触顶后请求会直接返回错误提示，消息大致是 "You have reached your specified API usage limits"。这是官方提供的、唯一真正意义上的硬性成本闸门，比幻想"我不会超支"靠谱。

一句话总结：**先小额试，确认能正常调用、账单正常，再考虑补到 $100 并开自动充值。**

## 国内卡付不过去，大家实际在用这四条路

如果你手里没有稳定的海外信用卡，或者账单地址和 IP 环境过不了风控，官方直充会在第 5 步卡死。下面几条路各有代价，没有哪条是白捡的。

| 路径 | 你需要准备 | 实际成本 | 适合谁 |
| --- | --- | --- | --- |
| 官方 Console 直充 | 国际信用卡 + 与卡一致的账单地址 + 支持地区的网络环境 | 面值 + 约 1%–3% 的货币转换费 | 有稳定海外支付条件的人 |
| 走云平台（Bedrock / Vertex AI） | 云账号、云预算 | 按云厂商计价 | 主体和预算本来就在云上的团队 |
| 订阅代付 / 开发者中转平台 | 平台账号 + 微信或支付宝 | 高于官方原价，具体看方案 | 没海外卡、想省掉折腾的人 |
| 聚合 / 中转 API 平台 | 平台账号 | 按量计费，部分平台充值时另加手续费（有用户提到某平台约 5%） | 想用一个 key 调多家模型的人 |

说一下第四类的货币成本：有论坛用户提到某些聚合平台充值要多付约 5% 的费用，这比官方直充叠加银行 1%–3% 的货币转换费还高。如果只是偶尔调用，5% 无所谓；如果是长期大额跑量，这个差价会变成实打实的预算。

另外，国内银行发行的外币卡在 Anthropic 这类订阅场景被拒是常见现象，原因往往不是余额，而是账单地址、3D 验证、线上交易开关或银行的风控。连续重试多次反而容易触发银行侧的拦截，遇到被拒，先打电话问银行具体原因，比继续点购买按钮有用。

## 那到底该选哪条

判断顺序其实很短：

**如果你有能正常付款的海外卡**，直接走 Console 官方充值，先充 $20 试通，再补到 $100 并打开自动充值。没有任何第三方通道值得你为此多付两三成。

**如果你有云预算或企业主体**，先看 Bedrock / Vertex AI 里的 Claude。账单可审计、额度可扩容、后续迁移成本低，比硬凑一条个人直充通道更接近真实部署需求。

**如果你没有海外卡，但只需要"能调 Claude 的额度"**，WildAI 这类代付和开发者 API 方案是合理的中间选项。你要清楚买的是平台侧额度，不是官方 credits。

**如果你要官方账单、合规发票或指定区域**，第三方平台一律不适用，这种情况下应该走官方销售渠道谈月度发票。

## 几个经常被问到的点

**充 $100 是不是官方单次充值上限？**
购买弹窗里 $5 / $20 / $100 是预设金额，旁边还有自定义选项。所谓"$100 是单次上限"的说法来自第三方整理，我没在 Anthropic 官方帮助中心看到对应说明，别把它当成硬顶。

**充错体系能退吗？**
额度购买概不退款，一年到期也不能延长。充之前确认你要的是 API 额度还是 claude.ai 订阅。

**余额用完了会怎样？**
在补充额度之前，API 和 playground 都无法调用。所以自动充值对生产环境几乎是必选项。

**第三方平台的额度会不会突然用不了？**
有可能。通道、库存和平台政策都会变，这也是为什么建议先买小额、确认可用之后再续。任何要求你一次性充大额的说法都值得多看一眼。

**付不进去能先试小额吗？**
能，而且应该。官方和第三方都从小额开始：前者确认卡和账单地址没问题，后者确认额度和通路能正常调用。$100 这个数字放在测试之后，而不是测试之前。
